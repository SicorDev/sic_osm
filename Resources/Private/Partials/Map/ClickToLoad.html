Two-click solution: the static map is shown first – nothing is loaded from third parties. The button loads Leaflet (from this extension) and replaces the image by the interactive map at the same place; only then the visitor's browser requests tiles from the tile server named in the hint. "Remember for this visit" stores the choice in sessionStorage (no cookie), further two-click maps then open interactively right away. Without JavaScript the static map stays fully usable (the bar is hidden). Leaflet is loaded on demand by sic_osm.js – the URLs are passed in data attributes.
